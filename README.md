# 📦 Sistema Web de Control de Inventarios y Pedidos

Un sistema de gestión optimizado diseñado para ayudar a pequeños emprendimientos a llevar el control en tiempo real de sus insumos, cálculo automático de costos de producción y registro de órdenes de venta.

---

## 🚀 Características Principales

* **Módulo de Inventarios:** Registro, edición y eliminación de insumos con control de stock mínimo.
* **Calculadora de Costos:** Cálculo automático de costo por unidad basado en recetas/fórmulas de ingredientes.
* **Gestión de Pedidos:** Control de estados de entregas y fechas de compromisos.
* **Base de Datos Relacional:** Consultas optimizadas para reportes rápidos.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python (Flask)
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Base de Datos:** MySQL / SQL Server
* **Herramientas:** Git, VS Code
